# 📝 网页文本分析工具（多图可视化版）

基于 Streamlit 的中文文本分析工具，支持网页抓取、关键词提取和多维度数据可视化。

## ✨ 功能特性

- 🌐 **网页URL爬取分析** - 自动抓取任意网页文本内容
- 📝 **手动输入文本分析** - 支持直接输入文本进行分析
- 🔍 **中文分词** - 使用 jieba 进行精准中文分词
- ☁️ **词云可视化** - 新增词云展示功能
- 📊 **多维度图表** - 柱状图、饼图、折线图、词云
- 🎨 **配色方案** - 支持专业蓝、活力橙、自然绿、彩虹色
- 📥 **数据导出** - 支持CSV格式下载

## 🚀 快速开始

### 环境要求

## 📖 使用说明

### 模式一：网页URL爬取分析

1. 选择 "🌐 网页URL爬取分析" 模式
2. 输入有效文章URL（建议使用新闻文章、博客等文本丰富的页面）
3. 点击 "🚀 开始爬取网页文本"
4. 爬取成功后，点击 "📊 开始文本分析"

### 模式二：手动输入文本分析

1. 选择 "📝 手动输入文本分析" 模式
2. 在文本框中输入待分析文本
3. 点击 "✅ 确认输入文本"
4. 点击 "📊 开始文本分析"

### 参数配置

- **关键词数量**: 3-20个，默认10个
- **配色方案**: 专业蓝、活力橙、自然绿、彩虹色

## 🔧 配置说明

### 超时设置

网页抓取默认超时时间为15秒，可在 `crawl_web_text` 函数中调整：

```python
def crawl_web_text(url, timeout=15):
    # timeout 参数控制超时时间
```

### 停用词配置

停用词列表可在 `analyze_text` 函数中修改：

```python
stop_words = {"的", "了", "是", "我", ...}
```
